# Figma UI/UX Prototypes

This document provides the Figma design and interactive prototype links for the **Token Learning Platform**, along with a summary of the linked screens and navigation flows.

## Links
- **Figma Design & Interactive Prototype:** https://www.figma.com/design/WtbF65PsIM1vaXk9eADdyM/Token-Learning-Platform---Sprint-2-UI?node-id=1-483&t=S9rJ84gubprUV3pZ-1

## Designed & Linked Screens

| # | Screen | Key Components & States | Primary Prototype Transitions |
|---|---|---|---|
| 1 | **Sign-In** | Email/password login, Sign-Up toggle with welcome token notice | Sign-In -> Lesson Search |
| 2 | **Profile** | User bio, educator/pupil role badges, rating summary, skill tags | Top Nav -> Core Views; Create New Lesson -> Create Lesson |
| 3 | **Wallet & Transaction History** | Available balance vs. Escrowed balance cards, ledger table | Booking reference -> My Bookings |
| 4 | **Lesson Search** | Keyword search, category/price/rating filters, lesson card grid | View Details -> Lesson Detail & Booking |
| 5 | **Lesson Detail & Booking** | Syllabus, slot picker, escrow explanation, Request Booking CTA | Request Booking -> My Bookings |
| 6 | **Create Lesson (with Price Guidance)** | Lesson form, slot builder, category-based token price guidance | Publish Lesson -> Lesson Search |
| 7 | **My Bookings** | Status tabs (`Pending`, `Confirmed`, `Completed`, `Disputed`), Complete/Rate/Dispute actions | Raise Dispute -> Dispute |
| 8 | **Dispute** | Frozen escrow indicator, reason selector, evidence upload, submission | Submit Dispute -> Admin Panel |
| 9 | **Admin Panel** | Dispute queue, pupil/educator evidence review, Refund / Release / Split controls | Resolution action -> My Bookings |
